# Agent Note: Windows 7 原生设置窗口的持久化、输入、标点、快捷键、工具栏与维护

Status: implemented

## Problem

现有 Windows 设置使用 WinUI 3，无法作为 Win7 设置入口。兼容窗口必须使用相同配置、默认值和版本能力过滤，并且不能在保存少数字段时抹掉其他页面、令牌或另一窗口的修改。完整页面适配期间也不能把普通 Windows 的设置入口切到未完成的窗口。

## Decision

`settings/win7` 使用 Win32 标准控件和系统字体、颜色、DPI，复用不依赖 WinRT 的页面模型与同一个 Rust Host API。独立目标 `msime-client-settings-win7` 目前提供快捷键的按键设置与按键速查，以及悬浮工具栏的显示、按钮与尺寸控件；维护与诊断页提供服务与 TSF 日志开关、服务重启、目录打开和设置文件导入导出。只有同时含中文与日语方案的版本显示日语切换控件，不提供手写的版本不画手写按钮开关；不添加未实现页面的占位入口。工具栏图形预览和颜色页跳转尚未完成。普通构建、启动器、安装包及出厂默认值保持现状。

`PreferencesStore` 保留完整快照，按明确存在的路径及契约登记的可省略叶字段与类型替换值，带原修订号调用 Rust 的比较并交换保存。默认值、配置格式、字段校验和磁盘提交均由 Rust 负责。切换中英文的三个互斥布尔值在一次保存中修改；不改动无关字段。工具栏尺寸复用 `FloatingToolbarSizeModel.h`，一次保存缩放与字体尺寸；已有自定义值照实显示，进入页面不归一化存储。当前 C ABI 没有冲突错误码，适配器识别其实际描述 `preferences changed; reload before saving`，并以集成测试约束这一边界。

输入页接通「选词与翻页」：以词定字、退格回退与六组可配置导航键。以词定字的组合框只列当前未用于翻页的键组；把它正在使用的键组改为翻页时，同一次 Rust 保存关闭以词定字，避免中间态冲突。选择关闭保留记住的键组。Tab 与 PageUp/PageDown 在 Windows 固定生效，界面说明这一行为，不修改文档里对应的共享偏好。`navigation.mouse_wheel` 为假、`backspace_reverts_selection` 为真时共享格式省略该字段，界面按契约展示，首次修改只允许补入这两个明确的布尔叶字段；未知键、类型不对与缺少中间对象仍被拒绝。页面切换和刷新只读当前值，不把现代窗口的展示回退值写成默认值。输入页还提供「输出设置」标签：简体与繁体、同次上屏中英文之间加空格，以及会话初始全半角。繁简只改现有布尔键，不触碰其他宿主的繁体变体；说明复用 `InputSettingsModel.h`，随实际方案与选择更新。快捷键与输入各自记住已选标签，换页、换标签均只读，不改修订号。输入页的「候选与联想」提供云候选、混输总开关、英文与首页数量、emoji、符号、颜文字、版本允许时的临时日文、学习、只出单字和本地整句联想；混输关闭时禁用子项但保留值，不修改 Windows 固定使用的最短触发长度。「中英模式」接通默认中英文、按应用记忆与全局统一、光标旁切换提示，以及应用例外的新增、切换模式和移除。应用名复用 `AppInputModeRuleList.h` 规范化与即时提示，最终仍由 Rust 校验；粘贴路径取文件名、ASCII 转小写，中文名称走严格 UTF-16/UTF-8。修改一条规则保留整表中的其他平台标识，空表按共享格式省略。列表刷新保留仍存在的选中应用；无选择时禁用修改与移除。输入方案仍需继续适配。

输入页的「高级选项」复用 `InputSettingsModel.h` 的快捷模式、模糊音规则与依赖关系。Shift 总开关仅禁用通过 Shift+字母进入的模式，`/` 与 `@` 独立，地名依赖 `@` 模式；禁用不清除选择。模糊音首次启用在一次保存中启用全部规则并写 `seeded`；后续开关保留规则，确认重置时关闭并清空规则而保留 `seeded`，取消不写入。调频提供五种模式，学习关闭时禁用整组，关闭调频时禁用触发频次，只有线性模式启用步长，原值均保留；Rust 接受的 7–10 作为现有值展示，界面不擅自压到标准档位 1–6。

辅助码只在提供全拼或双拼的版本显示，两族各自控制启用、方案和候选中显示。自定义码表经 `msime_client_helpcode_schemas` 读取，插件经 `msime_client_plugins` 的 catalog 读取，均在工作线程执行，进入输入页或重新读取时刷新。采用现代窗口相同的宿主选项来源；读取有大小上限。资源或插件缺失时保留当前选项，页面刷新不改变修订。选择插件仅改整份 `plugins` 中对应的族，保留其他插件配置与原方案；选择普通方案同次清除对应插件。`plugins` 在全默认时会被 Rust 整体省略，因此存储只额外允许补入这一个明确的对象；不允许补造任意中间路径。辅助码触发方式等隐藏字段原样保留。

「标点与翻译」页目前接通标点组，尚无候选释义与翻译服务分组。标点模式、锁定和智能标点复用现代窗口的 `PunctuationSettings.h`：选「始终」只改本机锁定，保留起始标点；选普通中英文标点在一次保存里解除锁定并写起始标点。智能标点总开关同次修改总开关、数字后直出和字母后直出三个键，其他子项保留。关闭总开关时子项禁用并保留原值；两种直出都关闭时展示共享模型的惰性提示。引号和方头括号样式、空格开关属于默认时省略的字段，存储适配器仅允许按契约类型补入这些叶字段，不允许补造未知配置树。

云候选配置独立保留表单草稿，来源、方法、响应格式及文本编辑都不立即落盘。保存按钮将来源、地址、请求头、请求体、响应路径、超时与缓存作为一个对象交给原 Rust 校验和 CAS 持久化；无效配置不改变修订号，保留草稿并提示。无关偏好保存后仅当实际云候选对象改变才重填表单，避免把未保存编辑抹掉；并发保存冲突时重新读取实际服务配置，旧草稿不自动重试覆盖。请求头仅在本机保存，保存表单不发网络请求。文本通过严格 UTF-16/UTF-8 转换，业务校验不复制到 C++。

所有配置和运行时选项文件读写在串行工作线程执行；界面等待时禁用编辑控件，不累积整份旧快照。保存失败后重新读取实际状态并提示，既处理并发冲突，也处理可能已经落盘后清理失败的情况，不自动重试覆盖。关闭时完成已受理的保存并等待线程退出；完成消息不传堆指针，不把结果发给已销毁窗口。状态目录优先级与现代窗口一致，读取运行时选项有大小上限。

设置文件通过现有 Rust 导出与导入接口处理，复用 `SettingsDocumentFile.h` 的大小、UTF-8 和文件写入约束。导入带当前修订号，不覆盖并发修改；服务配置与密钥、诊断日志、使用统计和剪贴板历史开关按共享规则保留。文件选择在窗口的 STA 使用从 Vista 起支持的 `IFileDialog`，文件内容的读写与导入仍在串行工作线程执行。服务重启复用当前 edition 的 Aux 管道，仅提示是否已发送请求；目录打开优先实际日志子目录，不存在则打开数据目录。

独立 CMake 目标使用同架构、同源核心导入库；开发时可指定既有原生依赖前缀，CI 使用此目录的最小 vcpkg 清单，仅安装现有锁定版本的 JSON 依赖。`windows-settings` 在构建同源普通核心后构建和运行此目标，现代 WinUI 页面验收继续保留。CI 覆盖控件和存储，专用 Win7 核心、运行库与实机兼容性继续单独验证。

每个配置的程序目录生成同源 `edition.json`，使 Rust 的包身份与 C++ 的编译期 edition 一致；不能让独立编译的五笔等版本因缺少声明而在 C ABI 一侧被当作 full。

偏好默认值仍按安装准备阶段写入状态目录的 `edition` 记录读取，与包内声明分别验证。原生测试为非 full 版本建立同样的合成记录，断言首次偏好中的方案与本版本一致；不把未准备的空目录冒充已安装产品。full、五笔和日文的 x64 控件与配置测试通过，日文手写的原生窗口和 C ABI 均拒绝未提供的功能。

## Testing

Windows 11 上 MSVC `/W4 /WX` 的 x64 与 x86 构建均通过。真实同源 Win7 Rust 核心的集成测试覆盖修订号冲突、无效字段与类型拒绝、合成令牌与无关字段保留、窗口组合框和复选框通知经工作线程落盘、外部更新后界面刷新，以及关闭窗口时完成已受理保存。按键速查保留 Windows 固定支持的 Tab 和 Page Up/Down，不因对应共享偏好关闭而错误隐藏。工具栏测试还覆盖标准尺寸的单次提交、自定义尺寸仅展示不改写和按钮开关经实际控件保存。维护页测试覆盖两种日志开关、真实设置文件导出后经控件修改并导入恢复、保留合成令牌和本机日志状态，以及取消选择时不写入。文件选择器通过构造参数注入合成路径，按钮通知、工作线程、文件读写与 Rust 保存仍走正式路径；不把这项集成测试计作系统文件对话框的桌面验收。Windows 11 上曾使用默认设置程序打开并取消导出、导入的 `IFileDialog`，取消后无导出或导入；但当前远端仅有 Session 0，不能把这项结果计作用户交互桌面验收。独立验收脚本为 `tests/tools/windows7_settings.ps1`，用户桌面与 Win7 SP1 均仍需验证。最小 vcpkg 清单的安装、CMake 配置、编译与测试已在远端复现通过；workflow 经 `actionlint` 检查通过，尚未在 GitHub Actions 上运行。

选词与翻页的实际控件测试在 full x64/x86、五笔 x64、日文 x64 上通过，覆盖以词定字与翻页冲突时仅增加一次修订、关闭后记住键组、滚轮偏好从省略到开启再关闭的往返、退格回退字段的省略默认值，以及保留 Tab/PageUpDown 存储值和合成令牌。页面切换自身不修改修订号。

输出与标点控件在相同四组构建上通过，覆盖繁简不改繁体变体、空格往返、全半角修改、锁定保留起始标点、解除锁定的单次保存、引号与括号样式回到默认时重新省略、未知枚举和错误类型拒绝、智能标点三字段的单次修订，以及子项禁用与原值保留。

候选页在同样四组构建上通过原生集成测试和现有导入审计。覆盖混输关闭保留子项、可省略开关与首页数量往返、不修改最短触发长度、按版本过滤日文、云候选无效 JSON 不落盘并保留草稿、无关设置保存不抹草稿、合成中文 POST 模板的严格文本转换、超时非整数拒绝，以及外部服务配置更新后的 CAS 冲突刷新。没有实际访问云服务，不能把配置测试计作网络功能验收。

中英模式在 full x64/x86、五笔 x64、日文 x64 上的构建、控件测试与现有导入审计通过，覆盖默认状态、全局作用域、提示开关、中文程序名与完整路径规范化、重复和错误后缀拒绝、修改与删除时保留其他平台规则，以及删空时恢复省略。文本转换抽到 `ControlText.h`，同时复跑云候选的中文模板路径。

高级选项在 full x64/x86、五笔 x64、日文 x64 上通过编译、控件测试和现有导入审计。覆盖各模式依赖与选择保留、首次模糊音启用仅一次修订、取消与确认清空、已 seeded 的空规则重启、已有 9/8 调频值的展示与修改、学习关闭保留调频值，以及合成码表与插件的真实目录读取、插件切换和清除的单次保存、另一族与无关插件项保留、资源删除后仍展示现有选项、无资源的版本能力过滤。目录和文件均为合成数据；未连接实际插件服务或外部账号。

最终应用的已知阻断导入检查均通过。该检查没有穷举所有 Win7 导出，也没有验证 VC 运行库、完整产品或真实 Win7 UI；不能据此声称完整 Win7 支持。

## Alternatives considered

- **用 UI Automation 贯通系统文件对话框。** 可以覆盖实际选择行为，但保存与打开的控件模型、自动补全及交互桌面状态都会影响驱动，服务会话中的不确定性还会掩盖应用的文件读写断言。集成测试在文件选择边界注入路径，系统对话框单独做桌面验收，不因驱动失败就跳过实际配置验证。

- **冻结旧 WebView2 并复用共享 React 设置。** 可减少界面适配量，但依赖停止维护的旧引擎，前端能力和当前插件也没有完整兼容保证。原生兼容窗口可以直接复用共享 Rust 业务接口与既有纯页面模型。
- **在 UI 线程直接调用配置 API。** 实现更少，但目录、文件与锁等待会阻塞窗口；串行工作线程维护一份实际读取的快照，明确保存与关闭的顺序。
- **冲突后自动合并并重试。** 可以减少用户重做，但多字段操作存在业务关系，重试可能覆盖另一窗口刚做出的选择。这里刷新并提示，由用户决定下一次修改。

## Consequences

兼容设置有了可执行、可持续测试的存储与原生窗口基础，现代入口仍保持完整功能。代价是维护第二种 UI 承载，当前快捷键页、工具栏设置控件、输入页的中英模式、选词、候选、输出和高级选项、标点组和维护与诊断操作可用，工具栏预览与跳转仍未完成；仍需逐页复用共享模型、覆盖所有操作，并在 Win7 SP1 和现代 Windows 上进行桌面与安装验收。
