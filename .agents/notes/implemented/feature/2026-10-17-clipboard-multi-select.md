# Agent Note: Android 剪贴板历史多选删除

Status: implemented

## Problem

剪贴板历史只能逐条删除或全部清空，用户无法一次选择若干条记录并在误删后撤销。

## Decision

本机历史面板增加多选模式和顶行操作。选中的文字集合只作为 UI 状态，删除仍按共享存储的既有单条契约执行；删除成功后在内存保留五秒的文本列表，面板显示撤销入口，撤销通过重新加入共享存储恢复。

## Alternatives considered

直接在 Android 层维护另一份历史快照可以一次写入，但会复制共享存储的排序、固定和容量规则，设置页与键盘容易分叉，因此沿用共享入口。

## Consequences

用户可以选择性清理并短时间撤回。撤销窗口只在当前输入法进程内有效，进程退出或超过五秒后不保留待恢复数据；设备测试应使用合成剪贴板内容覆盖选择、删除和撤销。
