# Agent Note: 九键左列选择延迟音节列表复制

Status: implemented

## Problem

`NineKeySession::choose_spelling` 在判断左列选项类型前就复制整个 `spellings` 列表。字母和数字选项不会创建锁定撤销记录，因此这份列表复制在这些常见路径上完全没有用途；音节选项也只需要把列表保存到撤销状态。

## Decision

先记录是否处于重新选择状态，只有音节选项才准备撤销列表。普通音节选择把当前 `spellings` 缓冲移动进撤销记录，重新选择继续使用 `undo_last_lock` 返回的旧列表；字母和数字选择不复制也不移动列表。刷新仍在同一分支末尾重建左列。

## Alternatives considered

- **继续在分支前克隆列表**：实现最直接，但字母/数字选项和刷新前都会复制所有字符串。
- **所有选项都移动列表**：会让字母/数字选择丢失刷新前的列表状态，重新选择和失败路径无法保持原有行为。
- **改用共享引用保存撤销列表**：撤销记录跨越后续数字编辑，引用会把可变候选状态的生命周期扩展到整个九键会话。

## Verification

新增字母选项分配回归。旧实现为 355 次分配，延迟列表复制后为 347 次。九键与注音九键 74 项测试、Clippy、Rustfmt 和差异检查通过。

## Consequences

字母和数字左列选择不再复制无用的 `spellings` 字符串；普通音节选择复用当前列表缓冲，重新选词保留原有撤销数据，刷新后的候选和左列顺序不变。
