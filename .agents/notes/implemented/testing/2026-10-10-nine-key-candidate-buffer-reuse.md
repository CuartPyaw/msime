# Agent Note: 九键候选缓冲复用

Status: implemented

## Problem

九键刷新开始时会清空 `self.candidates`，随后用 `Vec::with_capacity(CANDIDATE_LIMIT)` 创建新的局部候选向量。旧向量的容量因此无法跨刷新复用，连续按键会重复申请候选行存储。

## Decision

拼音九键刷新接管已有的 `self.candidates`，清空长度后继续填充，保留向量容量。非活动和纯英文路径的行为保持不变。

## Alternatives considered

- 每次按键新建固定容量向量：实现简单，但丢弃上一刷新可复用的候选行存储。
- 逐行复用词条字符串：需要改写查询与排序的填充方式，超出本片向量容量复用的范围。

## Verification

新增刷新两次后候选向量指针和容量保持不变的回归测试；旧实现测试确实因指针变化失败，复用实现通过。九键模块 131 项测试通过。

## Consequences

连续九键刷新复用已有候选向量容量；`clear()` 仍会析构词条并释放字符串，本片没有实现词条字段的跨刷新复用；首次刷新仍按正常向量增长建立存储，候选排序、过滤、上限和输出字段保持不变。
