# Agent Note: 九键选择借用候选行

Status: implemented

## Problem

`NineKeySession::select` 在所有九键候选上先克隆完整 `WordItem`。常见的学习关闭选择只需要候选来源、覆盖的数字长度和提交词文本，却仍复制 canonical 读音、纠错信息、句子边界及其它行字段。

## Decision

选择入口直接借用候选行，先保存来源、固定位置、`pinyin` 长度和提交词文本；只有学习开启且候选需要学习读音时才复制 canonical pinyin。候选借用结束后再执行频率调整、消费数字和刷新。学习函数改为接收这些字段的借用，活跃分段直接追加读音，整句存储时才创建拥有型写入参数。

## Alternatives considered

- **继续克隆完整 `WordItem`**：实现简单，但学习关闭的普通九键选择会复制不会使用的行字段。
- **把候选行从列表中移出再写回**：可以移动所有权，但会改变刷新期间的候选列表结构和失败路径。
- **让频率和词典接口长期持有候选借用**：会把候选列表生命周期扩展进可变词典操作，超出选择入口的必要范围。

## Verification

新增九键普通候选选择分配回归。旧实现为 3 次分配，借用实现为 1 次；提交词文本和九键状态保持不变。九键与注音九键 73 项测试、引擎完整测试（1344 个单元测试、31 个 golden）、Clippy、Rustfmt 和差异检查通过。

## Consequences

学习关闭的九键选择不再复制完整候选行；学习开启、部分选词、整句存储、频率调整、诊断和数字消费顺序保持原有行为。
