# Agent Note: 固定位置方案入口守卫

Status: implemented

## Problem

候选刷新在不支持固定位置的方案中仍会先检查个人日志路径。该文件系统检查发生在日文、韩文、粤拼、注音和笔画等方案的每次候选刷新上，但这些方案不会进入固定位置处理。

## Decision

先判定当前候选列表是否属于普通固定位置、超级简拼或英文候选路径；其余方案直接返回，再读取日志存在性。支持固定位置的路径继续沿用已缓存的日志路径和在线候选规则。

## Alternatives considered

把日志检查继续放在入口顶部会保留无关方案的文件系统访问；在每个方案分支内分别检查会重复条件和路径判断，因此统一在分支选择前判定。

## Verification

完整引擎单元与 golden 测试、Clippy、Rustfmt、diff 检查、笔记检查和 quick 门禁覆盖提交。

## Consequences

不支持固定位置的候选刷新不再访问个人日志路径；普通、超级简拼、英文和在线候选仍执行原有固定位置与动态候选处理。
