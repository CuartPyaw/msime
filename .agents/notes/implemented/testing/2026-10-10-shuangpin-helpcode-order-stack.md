# Agent Note: 双拼单字辅助码短排列使用栈上索引

Status: implemented

## Problem

单字辅助码过滤会先把匹配类别转换成排列索引，再原地重排候选。常见候选批次不超过 64 行，却仍为这个短命 `Vec<usize>` 分配堆内存。

## Decision

候选不超过 64 行时使用固定栈数组保存排列索引；更大的批次继续使用按候选数量分配的索引缓冲。首匹配、次匹配、未匹配的顺序和后续未匹配行拆分保持不变。

## Alternatives considered

- **始终使用堆上的排列向量**：逻辑简单，但每次短辅助码查询都会多一次临时分配。
- **所有批次都使用大栈数组**：可去掉堆分配，但会让大候选列表在栈上占用固定空间。
- **直接分组复制候选行**：能省索引状态，却会重新分配候选文字和读音，恢复此前已消除的主要开销。

## Verification

新增短辅助码重排分配回归测试；旧实现产生 1 次排列索引分配并失败，栈上路径降为 0 次。双拼字典测试、完整引擎测试、Clippy、格式检查和 quick 门禁覆盖实现。

## Consequences

短辅助码查询不再为排列索引分配堆内存；大批次仍按原有可扩展路径处理，候选顺序和所有权保持不变。
