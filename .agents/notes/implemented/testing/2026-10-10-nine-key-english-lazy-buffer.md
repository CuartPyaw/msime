# Agent Note: 九键英文空结果延后缓冲

Status: implemented

## Problem

九键英文查询按候选前缀数乘单前缀上限预留 `words`，但数字可能没有任何英文词条，或所有数据库行会被九键数字匹配过滤。空结果仍占用理论页容量。

## Decision

英文词条结果向量改为空创建，首次通过数字匹配过滤的词条才按原理论上限 `reserve_exact`。英文候选排序、去重和前缀查询顺序保持不变。

## Alternatives considered

- 查询前按前缀上限预留：命中路径少一次容量判断，但无匹配数字会分配无用空间。
- 逐词自然扩容：空结果同样无分配，但命中页会改变原容量提示和扩容次数。

## Verification

新增无匹配数字 `999999` 的回归测试，断言结果为空且容量为 0；旧实现实际容量为 320，测试先失败，延后预留后通过。九键模块 132 项测试通过。

## Consequences

英文九键空结果不再预留前缀理论上限；首次有效结果仍一次预留原上限，输出内容和排序保持一致。
