# Agent Note: 个人上下文记录跳过中间词行

Status: implemented

## Problem

每次词典候选提交记录个人上下文时，先把一个词或句子边界转换成临时 `Vec<(&str, u32)>`，随后才遍历它构造真正写入模型的转换行。词典行因此为不会跨越调用边界的中间列表额外分配一次。

## Decision

直接从现有词文本或句子边界切片遍历，并按来源在遍历时计算计数；只保留最终的 `PersonalTransition` 缓冲。词典行仍按两次计数，生成句子的首行仍按连续组字状态使用两次计数，其余行为不变。

## Alternatives considered

- **继续构造中间词行列表**：逻辑直观，但每次个人上下文学习都会多一次短命堆分配。
- **把 `PersonalTransition` 改成借用字段**：个人模型和异步写入队列都需要拥有字符串，会把所有权边界扩展到用户词典层。
- **只优化词典候选、跳过生成句子**：可减少改动，但会保留重复的双路径逻辑；统一遍历同时覆盖两种合法来源。

## Verification

新增词典候选个人上下文分配回归：旧实现单独运行产生 72 次分配，优化后不超过 71 次；旧实现回退运行按上限断言失败。完整 `msime-engine` 测试、Clippy、Rustfmt 和 quick 门禁随后验证。

## Consequences

个人上下文记录不再构造中间词行列表，模型更新、提交链推进、连续句子计数和持久化内容保持不变。
