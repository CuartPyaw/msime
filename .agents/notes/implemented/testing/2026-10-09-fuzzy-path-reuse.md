# Agent Note: 模糊拼音 beam 复用父路径

Status: implemented

## Problem

`fuzzy_segmentations` 为每个父路径和每个模糊读音都复制一份路径向量。每轮扩展中最后一个实际采用的分支也会复制父路径，产生一次可以直接转移父向量的临时分配。

## Decision

按 beam 剩余容量先处理需要保留的前几个替代读音，最后一个输出分支直接取得父路径并追加读音；达到上限时只处理允许的前缀分支。外层顺序、路径上限、原始路径过滤和每个替代字符串的所有权保持不变。

## Alternatives considered

- **继续复制所有扩展路径**：代码直观，但每个父路径的最后一个扩展会额外申请路径向量。
- **原地扩展父路径后再回滚**：需要保存长度并处理达到上限的中途退出，容易让路径顺序和所有权回滚出错。
- **把所有路径放入一块连续缓冲**：能进一步减少外层分配，但会改变返回的 `Vec<Vec<String>>` 结构和后续路径所有权。

## Verification

新增 `zan`、`fa` 全模糊规则 beam 分配回归，旧实现为 45 次分配，复用父路径后为 40 次；模糊拼音测试 5 项、引擎全量单元测试 1371 项、golden 测试 31 项、doc tests、Clippy、Rustfmt、差异检查、笔记校验和 `bash scripts/verify-local.sh --quick` 均通过。

## Consequences

每个 beam 层的最后一个扩展复用已有路径向量，减少一次短命路径分配；模糊候选的顺序、上限、结果内容和原始输入排除规则保持不变。
