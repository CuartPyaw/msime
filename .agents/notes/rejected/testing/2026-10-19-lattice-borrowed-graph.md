# Agent Note: 词网格借用缓存字段至解码结束

Status: rejected — 有效完整配对的三个空页控制超过1.05预算，撤回生产改动

## Problem

默认 Runtime 九键仍未达到 p95 16ms。`build_graph_borrowed` 已从稳定缓存页读取行，但每条图边仍复制词面与读音，随后解码仅将它们当只读字符串使用。缓存页的借用覆盖整个同步合并调用，这些图内副本并非维持生命周期所必需；拥有型查询则仍需字段移交。

## Proposal

内部 `Edge`、`Graph` 与解码助手以字符串存储类型参数化，默认 `String` 保持拥有型入口，借用建图采用 `Cow<str>`。显式读音与词面借用外部行；空读音按原跨度生成拥有键；重复跨度只克隆 `Cow`，不引用图自身。同一解码实现用 `AsRef<str>` 只读字段，实际保留的路径继续生成独立 `String`；纠错附加图通过 `From<String>` 保持拥有字段。泛型仅在引擎内部，不增加公开接口、依赖、unsafe、跨调用缓存或引用计数。

## Historical audit

已按 `build_graph_borrowed`、图边借用、`Graph` 生命周期、`Cow` 和跨度缓存检索活跃笔记，无相同实现。[跨度缓存页借用](../../implemented/testing/2026-10-17-lattice-span-cache-row-borrow.md)部分重叠，本片将其图边字段副本延后到实际输出；保留缓存预热、FIFO、长输入回退和查询顺序决定。[拥有行转移图边](../../implemented/testing/2026-10-14-lattice-graph-row-ownership.md)继续持有拥有查询的移交及原容量语义。[出边切片借用](../../implemented/testing/2026-10-15-lattice-outgoing-borrow.md)与[回溯物化](../../implemented/testing/2026-10-16-lattice-trace-materialization.md)继续持有评分遍历和最终输出。没有完全吸收、过时或需归档的笔记。

Rust 官方 [Cow](https://doc.rust-lang.org/std/borrow/enum.Cow.html) 与 [AsRef](https://doc.rust-lang.org/std/convert/trait.AsRef.html) 已核对借用、拥有克隆及只读转换契约。同仓库 `Prefix` 的 `Cow` 与词典借用页提供现有实现参考；根因由建图中的两处字段克隆及缓存调用寿命直接确认，实施准备充分，性能收益仍待测量。

## Alternatives considered

- 全部图边统一改 `Cow<str>`：可只保留一份解码实例，但会改动拥有型入口和大量冻结参考的字段构造；默认存储类型保留旧入口，代价是多一份解码单态化。
- 图边持有 `Arc<str>`：可以跨调用共享，但需要重塑词典缓存字段并为引用计数付费；目前同步调用内已有稳定借用，无需扩大持有范围。
- 继续复制字段：没有新类型参数，维护最少；但每次建图仍为最终未输出的边分配字符串，先用指针和精确分配预算证明可删除工作，再决定接入。

## Acceptance criteria

先在旧生产入口上使外部字段指针与分配减少断言真实失败，再实施最小改动。冻结本片基线 `43715313f397281bdc974e9c007b23b786920647` 的完整借用建图用于对照；验证查询顺序/次数、图边顺序/终点/评分位模式/标志、图容量及完整解码字段与浮点位模式。覆盖空页、空词面、空读音、Unicode、重复跨度、跨度上限、边数上限、普通/宽末列、有无备忘和语言模型及纠错附加图。输出在图和缓存页销毁后仍独立可用。拥有型入口原测试继续运行。

分配区间只创建图，不释放区间外输入；完整建图含析构的 System 分配器配对计时包含查询与跨度键构造，预先固定唯一/重复音节、显式/混合读音、空页、宽度1/8/32与长度1/4/12。每形状21对交替先后，较快臂校准至少20ms；有非空显式字段的目标中位新旧比<0.95，空页控制<1.05。全部形状收齐再统一判断；不换几何、放宽预算或挑选结果。外部构建出现则全轮无效并保留，可按原预算重跑一次，不据扰动轮作通过或失败结论。普通测试使用仓库现有计数分配器，计时二进制临时去掉全局包装注册以使用 System，编译后逐字恢复；记录二进制身份。若无稳定收益或控制失败则撤回生产改动，保存否决证据。

通过后运行完整锁定资源全拼60/九键81质量与候选对照、默认Runtime旧/新/新/旧四轮及16ms预算、相关完整测试、fmt、Clippy、notes、quick和独立复核，再逐片提交推送合并。端到端受外部构建干扰的轮次保留限制，不从局部分配或配对预算宣布16ms达标。

## Risks

双解码单态化增加代码体积，编译器布局可能改变速度；`Cow` 本身并不保证每个类型布局，须实际核对内存与计时。隐式跨度键仍需拥有，必须防止引用临时字符串或图内自引用。生命周期不得伸出缓存视图，输出仍拥有全部字段；长输入拥有型回退、纠错路径与数值顺序不能因泛型而漂移。没有文件读写、目录、权限或 Android 资源改动，不将编译检查称为设备验收。

## Rejection evidence

固定基线 `43715313f397281bdc974e9c007b23b786920647`。原建图在外部字段指针与非空字段分配预算上真实失败两项；原型四项专项通过，含800组建图、查询、容量、评分位模式、语言模型与纠错，以及销毁图和缓存后仍独立的输出。三个冻结函数去除注释和空白后与基线相同，独立复核未发现阻塞。首次绿色编译前的泛型推断与测试生命周期错误也保留，未放宽断言。绿色结果后仅增加代表性分配日志与移除冻结快照注释；撤回前未为该日志再次运行普通测试，不报告其数值。

完整建图配对每轮54形状、1134对。首轮156次监测中120次有构建，最多22个，整轮无效；不使用该轮的通过或失败判断。唯一一次原样重跑有效，112次监测均无构建，但一分钟负载40.67–93.50，不能证明机器独占或排除采样间短进程。

有效轮36个非空目标中位新旧比0.172805–0.908676，全部小于0.95；18个空页控制比0.716422–1.080507。重复音节下长度1/宽度1、长度1/宽度8、长度12/宽度1的空页控制分别为1.080507260、1.062547827、1.050396612，均超过预设1.05。完整预算退出101，因此撤回，不因省分配或多数目标提速放宽控制门槛，也不再重测挑选成绩。校准较快臂达到20ms，正式样本并非每个都保证20ms。

System计时二进制在运行前保存，测前测后SHA-256一致；临时全局分配器注册已逐字恢复为HEAD。生产建图、泛型解码及测试接线全部撤回，拥有入口与缓存页决定保持原样。没有对被否候选继续跑新质量、完整引擎/Runtime、ABBA或设备验收，16ms目标仍未达成。
