# Agent Note: 九键全拒绝投影不预留结果页

Status: rejected — 无构建观测的完整配对轮仍未达到事前收益与控制预算，生产入口保持原实现

## Problem

固定 `5d5095eb350e249cd115958bc816854536eea8b1` 的完整九键基线为81例、每臂1791键、5例预热，模型臂p95为27.19 ms、363键超出16 ms；36次观测未发现构建，不能从单轮推断相对历史回退。预热后12秒采样仍有线性层、二元备忘与申请释放；27次观测中25次有外部构建，仅用于定位。`query_filtered_rows` 借用页分支在谓词前按完整行数预留结果，即使全部拒绝仍申请并立即释放整页。

仅统计数字的临时插桩在相同完整两臂加预热中观察到145020次借用投影，其中7180次为空，仍累计预留1615084个136字节行槽。这是过程累计的逻辑容量，不是峰值或RSS；没有记录真实输入、词面或凭据。插桩源码已逐字恢复，统计运行的耗时不作性能成绩。

## Proposal

借用页以同一个过滤迭代器找首条保留行。没有保留行则返回零容量页；找到首行才按原完整行数一次预留，复制首行并继续消费同一迭代器。每条谓词仍只调用一次，顺序、系列热页标志和所有输出字段不变。非空投影保持原外层与字段容量；拥有页、模糊合并、冷页缩容、完整缓存、FIFO与失效规则不变。空投影的私有返回容量明确允许降为零。

## Historical audit

[冷页借用](../../implemented/testing/2026-10-16-nine-key-cold-cache-projection.md)与[复制前读法过滤](../../implemented/testing/2026-10-16-nine-key-filter-before-clone.md)部分重叠，继续持有完整缓存与字段副本决定；本片翻转其全拒绝页仍保留外层容量的限制，因此新建并互链。[排名支配过滤](../../implemented/testing/2026-10-16-nine-key-dominated-row-projection.md)继续持有冷页不得提前排名的规则，不改变谓词接纳标准。模型矩阵与二元前词散列已有负结果，不重新接入。没有完全吸收或过时提案。

## Alternatives considered

- 先数保留行再精确预留：非空稀疏页也能缩小，但要重复谓词，带状态的谓词会改变接纳结果。
- 所有页从空容器逐步增长：代码简单，空页也不申请，但增加非空页扩容并改变已有容量规则。
- 每次继续预留完整页：回调前就有结果存储，但全拒绝的数千个结果页没有消费者。

同仓库[路径页延后预留](../../implemented/testing/2026-10-11-nine-key-path-lazy-buffer.md)使用首次实际写入才申请的模式。已核对标准库[Iterator::next](https://doc.rust-lang.org/std/iter/trait.Iterator.html#tymethod.next)和[Vec::with_capacity](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.with_capacity)，不增加依赖或公开接口。

## Acceptance criteria

冻结当前完整 `query_filtered_rows`；热页全拒绝时严格少一次申请且返回容量为零，先在旧生产路径真实失败。覆盖冷/热、0/1/4/32/128行、全拒绝/首留/末留/半留/全留、模糊、无效输入、别名、纠错标记、带状态谓词访问顺序和实际cached标志；字段、缓存内容/容量/FIFO与失效状态一致，非空结果容量严格相等。旧测试的分配等式只加可独立计算的全拒绝页一次收益。

普通System分配器release完整SQLite筛选入口，2种键×4种行数×3种接纳模式（全拒绝/末条/全留）×冷热，共48格；每格40对交替先后，旧臂校准至少10 ms。热页32/128行全拒绝4格要求新/旧中位比小于0.98，其余44格小于1.05。两臂包含完整查询与结果析构，不改谓词或缓存建立范围，保留全部原始数据并统一判定。计时期间观测到构建时保留整轮，不作为无构建证据；无干扰完整轮失败不重测找绿或放宽预算。

完整引擎、golden、运行时、全targets Clippy、fmt、notes和本地quick通过；正式旧新全拼60与九键81例质量JSON相同，九键完整逐键ABBA仍保持16 ms门槛并报告未通过。提交、推送、创建独立PR并按已有授权直接合并，确认远端后清理本片worktree。

## Risks

首条接纳前的迭代改变编译器布局，非空与冷路径须受控制预算约束。只对全拒绝借用页改变返回容量，不改变词典缓存的完整页或模糊去重时序。累计槽位不能直接换算延迟收益，局部收益也不能证明端到端16 ms达标。

## Experiment outcome

候选最强的理由是可确定消除全拒绝借用页的一次申请：旧生产入口上新增测试真实失败，容量为1而非0；候选接入后词典124项通过、3项手动计时忽略，状态谓词的访问顺序、实际热页标志、非空输出全部字段与容量、缓存容量、FIFO和数据库失效均保持。完整引擎首轮2327项通过，唯一失败是既有精确分配预算：当前候选的完整热刷新为1696→553次申请，实际恢复旧生产入口后的独立运行确认1696→573，净省20次。初次隔离子进程目标标识误用导致的测试运行失败不参与分配比较，正确目标重跑日志单独保留。

但预设门槛要求4个热页全拒绝目标格全部小于0.98，其他44格全部小于1.05。两轮都完整收齐48格、每格40对、交替先后，旧臂校准至少10 ms，并包含完整查询与结果析构。第一轮72.17秒、69次观测中15次碰到外部clang/cargo/rustc，3个目标失败，该轮保留且不当无构建证据。第二轮67.11秒、64次观测均无构建，4个目标失败，另有`ni`/128行冷页全拒绝1.217557和`ni'hao`/1行热页全拒绝1.063353超过控制预算。两轮二进制SHA前后相同。没有无干扰失败后再重测，也没有跨轮挑格或放宽预算。

没有构建观测不等于完全没有系统噪声；控制格的大幅波动不能单独证明候选必然更慢，但同样不能证明它满足预定标准。申请减少不能替代完整入口的延迟证据，因此候选不进入生产。

生产`query_filtered_rows`恢复固定基线，既有筛选分配预算和完整刷新1123次差值保持原值。候选完整入口只保留在`empty_projection_tests.rs`的`cfg(test)`模块，冻结旧入口与其共享不变查询核心；测试保留确定性申请节省、状态、容量、FIFO、失效和完整48格计时夹具。两轮计时发生在候选仍接入生产入口时，隔离后的测试方法名及单态化位置不同，不能把旧成绩当作已重跑过隔离入口。

基线全拼60例与九键81例质量程序成功运行并保留JSON；由于候选被否且生产恢复，不再进行候选端到端质量比较或ABBA，不声称这两项通过。最初固定完整九键基线的模型p95为27.19 ms、363/1791键超过16 ms，性能总目标仍未完成。
